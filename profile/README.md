# Quantum PHP

Quantum PHP is a modular PHP framework focused on clear architecture, practical developer experience, and full project scaffolding out of the box.

## Repositories

- `framework` - the core framework package
- `project` - the starter project / application skeleton
- `docs` - the framework doecumentation

## Get Started

```bash
composer create-project quantum/project my-app
```
